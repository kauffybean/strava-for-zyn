## Why I Built This

This started as a joke with friends in San Diego (aka Zyn Diego). There’s a massive military presence here, and those guys love their nicotine pouches. Someone said, “What if there was a Strava for Zyns?” and I blacked out and made it real.

Zynfantry is what happens when meme energy meets full-stack ambition. It’s a little campy, definitely not FDA-approved, and probably one cigarette away from satire. But it’s also a surprisingly clean, scalable app that lets users log, analyze, and socially engage with their Zyn habits. Built fast. Built hard. Built for the troops.

## 🧠 Project Overview

Zynfantry is a full-stack social tracking app where users:
- Log their Zyn pouches (strength, flavor, mood, duration)
- Drop location pins with each Zyn session
- View analytics on consumption habits
- Connect with friends, comment, and react

Basically, it’s a social network for highly tactical nicotine usage.

---

## 🛠 Tech Stack

**Frontend**
- React (TypeScript)
- Tailwind CSS
- React Query
- React Hook Form
- Leaflet.js (for maps)

**Backend**
- Node.js + Express
- PostgreSQL
- Drizzle ORM
- Passport.js + session auth
